# 게임 보고서 양식 (초안 v0.1)

이 문서는 한 판(또는 한 캠페인)의 기존 로그를 모아 사람이 읽는 보고서로 정리하는 양식입니다. 각 항목 아래 `출처:`는 그 값을 어느 로그에서 가져오는지입니다. 양식이 확정되면 생성 스크립트(`make_report.py`, 미작성)로 자동 작성합니다.

- `{ }`는 채울 값입니다.
- **[신규 기록 필요]**는 지금 로그에 없어 추가 기록이 필요한 항목입니다.

로그 위치(한 판 기준):

| 로그 | 경로 | 내용 |
|---|---|---|
| 판 요약 | `runs/{game_id}/summary.json` | 결과, 지표, 호출 수, 대체·거부·거래 집계 |
| 상세 기록 | `runs/{game_id}/detail.jsonl` | 관측, 판단 이유, 선택 행동, 실행 결과, 질문 응답, 교섭, 경험 |
| 모델 호출 | `runs/{game_id}/codex-calls.jsonl` | 프롬프트 전문, 응답, 토큰 |
| 엔진 기록 | `runs/{campaign}/pool.sqlite3` | 게임 상태(정답·단서·배치·관계), 이벤트, 질문·거래 기록, 에이전트 이력·평판 |
| 캠페인 | `runs/{campaign}/batch.json`, `agent-memory/` | 판 순서, 조건, 에이전트별 교훈 |

## 부록 B. 생성 방식 (제안)

`make_report.py runs/{campaign} --game {seed}`로 1부를, `--campaign`으로 2부를 마크다운으로 만듭니다. 전개 표는 `detail.jsonl`을 결정 ID로 묶어 사이클·단계 순으로 정렬해 채웁니다.
